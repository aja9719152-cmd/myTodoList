## 1. 개요

My Tasks는 브라우저에서 바로 여는 개인용 할 일 관리 앱이다. 서버나 설치 없이 `index.html` 하나를 열면 동작하고, 데이터는 브라우저(localStorage)에 저장된다.

### 1.1 목표

- 할 일을 빠르게 추가·완료·정리할 수 있다.
- 카테고리(업무·개인·공부)와 진행률로 할 일 현황을 한눈에 파악할 수 있다.
- 휴대폰부터 넓은 데스크톱 모니터까지 화면 크기에 맞는 레이아웃을 제공한다.
- 키보드 사용자와 스크린 리더 사용자도 모든 기능을 쓸 수 있다.
- 실수로 지우거나 데이터가 손상되어도 복구할 수 있다.

### 1.2 범위 밖

- 회원가입·로그인, 서버 저장, 기기 간 동기화
- 마감일·알림·반복 일정
- 여러 사용자의 공동 편집

## 2. 기능 요구사항

각 요구사항의 "완료 기준"은 현재 구현에서 확인된 동작이다.

### F1. 할 일 기본 관리

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F1-1 | 할 일 추가 | Enter 키와 "추가" 버튼 모두 지원. 빈 내용이면 입력창이 흔들리며 추가되지 않음. 최대 200자 |
| F1-2 | 할 일 삭제 | 각 항목의 ✕ 버튼. 사라지는 애니메이션 후 삭제 |
| F1-3 | 완료 토글 | 체크박스로 완료/미완료 전환. 완료 항목은 취소선 |
| F1-4 | 인라인 수정 | 텍스트 더블클릭 또는 ✎ 버튼으로 편집. Enter 저장, Esc 취소, 바깥 클릭 시 저장. 편집 중 카테고리 변경 가능. 내용을 비우면 원래 내용 유지 |
| F1-5 | 중복 경고 | 같은 내용(대소문자·공백 무시)을 추가하면 확인 창. 수정으로 같아지면 경고 알림 |
| F1-6 | 생성 시간 표시 | "방금 전 / N분 전 / N시간 전 / N일 전", 7일이 지나면 날짜. 1분마다 갱신 |

### F2. 카테고리

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F2-1 | 3가지 카테고리 | 업무(work, #4A90E2), 개인(personal, #27AE60), 공부(study, #8E44AD) |
| F2-2 | 추가 시 선택 | 입력창 옆 드롭다운. 기본값 "개인" |
| F2-3 | 색상 태그 | 각 항목에 카테고리 색 태그 표시 |
| F2-4 | 카테고리 필터 | 전체/업무/개인/공부. 선택된 필터 강조, 선택 상태 저장 |
| F2-5 | 키워드 자동 분류 | 입력 중 키워드로 카테고리 자동 선택 (아래 F2-5 상세) |

**F2-5 키워드 자동 분류 상세**

- 입력하는 동안 키워드를 찾아 드롭다운을 자동으로 바꾸고, 입력창 아래에 `🏷️ '회의' → 업무`처럼 근거를 보여준다.
- 사용자가 드롭다운을 직접 고르면 자동으로 덮어쓰지 않고, 키워드와 다를 때만 "추천" 버튼을 보여준다.
- 할 일을 추가하면 직접 선택 표시를 초기화한다. 키워드가 없으면 사용자가 마지막으로 직접 고른 카테고리를 쓴다.
- "자동 분류" 체크박스로 끌 수 있고, 설정은 저장된다.
- 분류 규칙:
  - 긴 키워드가 우선한다. "산책"의 '책'이 공부로, "머신러닝"의 '러닝'이 운동으로 잡히지 않는다.
  - 한 글자 키워드와, 여러 카테고리에 걸칠 수 있는 단어(발표·세미나·면접·예약)는 쓰지 않는다.
  - 키워드가 많이 나온 카테고리가 이기고, 개수가 같으면 뒤에 나온 키워드를 따른다. 한국어는 핵심 명사가 뒤에 오기 때문이다("영어 회의 자료" → 업무).
- 적용 범위: 새로 추가하는 할 일에만 적용한다. 인라인 수정이나 가져오기에는 적용하지 않는다.

### F3. 정렬 · 검색

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F3-1 | 정렬 방식 | 완료 상태순(기본, 완료 항목은 아래로), 직접 정렬, 최신순, 오래된순, 카테고리순. 선택 저장 |
| F3-2 | 드래그 앤 드롭 | "직접 정렬"에서 ⋮⋮ 손잡이로 순서 변경. 마우스·터치 지원, 화면 끝에서 자동 스크롤, Esc로 취소 |
| F3-3 | 키보드 순서 변경 | 손잡이에 포커스 후 ↑/↓ 키 |
| F3-4 | 실시간 검색 | 입력하면 바로 걸러짐. 카테고리 필터와 함께 적용. 일치 부분 강조. Esc로 검색어 지움 |

### F4. 진행 현황 대시보드

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F4-1 | 전체 진행률 | "5/10 완료 (50%)" + 진행률 막대(부드러운 전환) |
| F4-2 | 카테고리별 진행률 | 카테고리마다 완료/전체와 작은 막대 |
| F4-3 | 오늘 추가된 할 일 | 로컬 날짜 기준 개수. 자정이 지나면 갱신 |
| F4-4 | 남은 할 일 배지 | 제목 옆에 미완료 개수. 바뀔 때 튀는 효과, 0이면 회색 |
| F4-5 | 응원 메시지 | 완료율 구간에 따라 7가지 문구 |
| F4-6 | 오늘의 격언 | 날짜마다 하나가 정해짐. 🔄 버튼으로 무작위 변경. 출처가 확실한 속담·인용구 15개 |

대시보드는 현재 필터·검색과 관계없이 전체 할 일을 기준으로 한다.

### F5. 데이터 관리

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F5-1 | 자동 저장 | 추가·삭제·수정·완료·순서 변경 시 자동 저장. 새로고침해도 유지 |
| F5-2 | 내보내기 | `my-tasks-YYYY-MM-DD.json` 파일 다운로드 |
| F5-3 | 가져오기 | JSON 파일 업로드. 현재 데이터가 있으면 합치기/바꾸기 선택 + 백업 파일 저장 여부 확인 (기본: 백업함) |
| F5-4 | 되돌리기 | 삭제·완료 항목 삭제·수정·가져오기를 최근 20개까지. 알림의 "되돌리기", ↶ 버튼, Ctrl+Z |
| F5-5 | 완료 항목 일괄 삭제 | 개수 표시, 확인 창 후 삭제. 필터와 관계없이 모든 카테고리 대상 |
| F5-6 | 다른 탭 동기화 | 다른 탭에서 바뀐 내용을 자동으로 불러옴 |

### F6. 테마

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| F6-1 | 다크/라이트 토글 | 오른쪽 위 스위치. 다크 색상: 배경 #1A1A1A, 카드 #2D2D2D, 텍스트 #E0E0E0 |
| F6-2 | 테마 저장 | 선택 저장. 저장값이 없으면 운영체제 설정을 따름. 새로고침 시 깜빡임 없음 |
| F6-3 | 전환 애니메이션 | 색이 0.3초 동안 부드럽게 바뀜 |

### F7. 키보드 단축키

| 단축키 | 동작 |
|---|---|
| Alt+N | 새 할 일 입력창으로 이동 |
| Alt+1 ~ 4 | 전체/업무/개인/공부 필터 |
| Alt+D | 다크 모드 전환 |
| Ctrl+Z | 되돌리기 (입력창 안에서는 원래의 글자 되돌리기) |

한글 입력 상태에서도 동작해야 한다.

### F8. 피드백

모든 조작에 눈에 보이는 반응이 있어야 한다.

- **애니메이션:** 추가는 페이드 인, 삭제는 페이드 아웃, 완료는 슬라이드, 수정은 강조, 빈 입력은 흔들림이다.
- **알림(토스트):** 삭제·되돌리기·가져오기·오류 결과를 알리고, 필요하면 "되돌리기"나 "모두 보기" 버튼을 함께 보여준다.
- **필터에 가려진 항목:** 추가하거나 수정한 항목이 현재 필터 때문에 안 보이면 알려준다.
- **모두 완료:** 모든 할 일을 완료하면 🎉 알림을 띄운다.

## 3. 비기능 요구사항

### N1. 반응형 레이아웃

| 화면 너비 | 레이아웃 |
|---|---|
| 1440px 이상 | 3단: 메뉴 · 할 일 목록 · 진행 현황. 양옆 패널 화면 고정 |
| 1024 ~ 1439px | 2단: 왼쪽에 메뉴와 진행 현황, 오른쪽에 목록 |
| 1920px 이상 | 가운데 열 최대 1100px, 전체 가운데 정렬 |
| 1024px 미만 | 카드 한 장 (위에서 아래로) |
| 480px 이하 | 터치 영역 44px 이상, 입력창 한 줄 전체 사용 |

- 데스크톱에서는 입력·검색 영역이 스크롤해도 화면 위에 고정된다.
- 터치 기기에서는 마우스를 올려야 보이던 버튼(✎, ✕)이 항상 보인다.

### N2. 성능

- 할 일이 100개 이상이어도 부드럽게 동작해야 한다.
- 검색은 입력이 멈춘 뒤 0.15초 후에 실행하고, 저장은 마지막 변경 0.3초 후에 한 번만 한다(디바운싱). 탭을 닫거나 숨길 때는 즉시 저장한다.
- 화면은 바뀐 항목만 다시 그린다. 항목 하나가 이동하면 화면 요소도 한 번만 옮긴다.

### N3. 접근성

- 모든 버튼과 입력에 의미 있는 이름(ARIA 레이블)이 있어야 한다. 예: "'보고서' 삭제".
- 상태 변화(추가·완료·이동·검색 결과 개수)를 스크린 리더로 알린다.
- 포커스 관리:
  - 삭제 후에는 이웃 항목으로, 확인 창을 닫으면 원래 위치로 포커스를 돌려준다.
  - 고정된 입력 영역이 포커스된 항목을 가리지 않아야 한다.
- 건너뛰기 링크를 제공하고, 운영체제의 "애니메이션 줄이기" 설정을 따른다.

### N4. 안정성 · 오류 처리

- **저장 데이터 손상:** 원본을 별도 키(`todos_corrupted_backup`)에 보관하고 빈 목록으로 시작한 뒤 알린다.
- **저장 공간 부족·저장 차단:** 경고하고 내보내기 백업을 안내한다.
- **잘못된 가져오기 파일:** 다음 경우 이유를 알려주고 거절한다. 일부 항목만 잘못되었으면 그 항목만 빼고 개수를 알린다.
  - .json이 아닌 파일, 5MB 초과, 빈 파일, 깨진 JSON
  - 다른 앱의 파일, 더 새 버전의 파일
- **백업 실패:** 백업을 요청했는데 실패하면 가져오기를 중단한다.
- **예상하지 못한 오류:** 알림으로 알린다(5초에 한 번까지).

### N5. 보안

- 사용자 입력은 HTML로 해석하지 않는다. 예를 들어 `<img onerror=...>`는 글자 그대로 표시된다.

## 4. 개발 이력

| 단계 | 내용 |
|---|---|
| 1 | 기본 구조: 추가·삭제·완료 토글, localStorage 저장 |
| 2 | 카테고리, 카테고리 필터, 생성 시간 표시, 완료 항목 아래로 정렬 |
| 3 | 진행률 대시보드, 인라인 수정, 애니메이션 |
| 4 | 다크 모드, 검색, 완료 항목 일괄 삭제, 남은 개수 배지, 단축키, 모바일 최적화 |
| 5 | 내보내기/가져오기, 정렬 옵션·드래그 정렬, 성능 최적화, 접근성, 중복 경고, 되돌리기, 격언, 응원 메시지, 오류 처리 |
| 6 | 키워드 자동 카테고리 분류 |
| 7 | 데스크톱 레이아웃(`web_version`) 제작 및 분석·보완 |
| 8 | 모바일·데스크톱 버전을 하나의 반응형 버전으로 통합 |
